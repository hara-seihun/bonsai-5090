# Static signed-W4 × two unsigned-A4 planes

Representation-changing control, separate from the transient IMMA negative and
stable DP4A. Original binary signs become persistent signed four-bit native-MMA
operands: `+1=0x1`, `-1=0xf`, arranged `[K/128,16,N]` 32-bit words. No persistent
byte weight matrix. Original FP16 weight scales remain `[K/128,N]`.

## Exact A8 map

For an existing signed A8 activation `q`, define `u=q+128` and unsigned nibbles
`lo=u%16`, `hi=u/16`. Then `q=lo+16*hi-128`. Within each K128:

```
Plo = sum_i w_i*lo_i
Phi = sum_i w_i*hi_i
H = sum_i w_i / 2 = countPositive - 64
dot = Plo + 16*Phi - 256*H
```

K128 makes the weight sum even; `H` is exactly representable in int8 [-64,64].
The [Lean and C++ witness](witness/README.md) covers signed-byte/nibble bridges,
arbitrary finite sums, signed-W4 encoding, correction and ±16384 integer bounds.
The consumer resets integers within K128, then continues with original FP16 W
scale times original FP32 activation scale. This is exact for the given A8
carrier, not exact pre-quantization FP32. FP32 split reduction may reassociate.

## Boundary costs

`produce()` calls the unchanged bitserial maxabs/RN-even A8 producer and a separate
Q8→two packed-nibble-plane conversion. Both are charged in inclusive graphs.
`project_carrier()` may share this production across projections; it still stages
both planes in shared memory, loads prepared W4 operands, computes the integer
correction, applies the original K128 scales and reduces split partials. The
recurring launcher allocates/synchronizes/configures nothing and is capture-safe.
Output row stride is explicit, token tails are masked for R1..32, N32/K128.
Invalid producer status makes the output NaN; the existing aggregate error stays
available for the engine's normal end synchronization. Required null buffers,
invalid plans/strides return explicit CUDA errors.

Static residency: W4 N*K/2 bytes, half-DC N*K/128 bytes, original scales
N*K/128*2 bytes, total **67 bytes/K128/output** versus prepared Q1's18 bytes.
Two activation planes together use R*K bytes, in addition to retained Q8 R*K and
its original metadata. Preparation is a one-time load transform, not omitted
recurring work. To fit the full engine, W4 must replace prepared Q1 signs rather
than coexist as a duplicate. For25,621,954,560 projection/head parameters this is
12,810,977,280 W4 bytes +200,171,520 half-DC +400,343,040 scale =13,411,491,840 bytes.
A B32ctx4608 target with the BF16 DSpark drafter has less than1GB before activation
and workspace at this residency; no general fit claim. Parent's eventual plain
B32/no-drafter route avoids5.39GB draft weights plus its KV. Default DP4A unchanged.

## Concrete compiler bill

CUDA13.1 accepts PTX `m16n8k64.row.col.s32.u4.s4.s32` on sm120a, but lowers it to
byte unpack helpers and **two IMMA.16832.U8.S8 per PTX MMA**. Four PTX operations
per K128 therefore cost eight native byte MMAs plus recurring compiler-generated
nibble expansion. The static representation does not remove that boundary. This
is a tested W4 encoding, not a claim of native S4 execution on this device.
`__launch_bounds__` keeps the1024-thread R32/tile128 launch within the64-register
limit. Exact GPU addressing, all recurring work and residency are part of the
paired trained benchmark; the parent owns any whole-model quality/integration.

## Reproduce

Compile only the new consumer, benchmark, stable bitserial kernels and GGUF reader:

```sh
bash experiments/binary-native4/build.sh /absolute/path/bench "$PWD"
# Or reuse the exact timed remote consumer object:
NATIVE4_OBJECT=/workspace/binary/native4/native4.o \
  bash /workspace/binary/native4/experiments/binary-native4/build.sh \
  /workspace/binary/native4/bench /workspace/binary/halo
flock /tmp/binary-gpu.lock timeout 55s /workspace/binary/native4/bench \
  /workspace/binary/models/Bonsai-27B-Q1_0.gguf round /workspace/binary/native4/results/round
```

producer once per fullR, shared conversion/consumer stages separately, DC/original

packing, transfers, allocation and graph construction are excluded from recurring
projection, with persistent bytes reported explicitly. A `round_complete` record
